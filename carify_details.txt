# Carify: Performance Hardware Marketplace - Project Details

## 1. Overview
Carify is a premium, multi-vendor e-commerce platform specifically designed for the GCC region, focusing on automotive parts, performance hardware, and specialized automotive services. The platform follows a high-performance "Industrial Tech" aesthetic, tailored for elite manufacturers and private collections.

## 2. Core Features
- **Unified Authentication**: Integrated sign-in/signup flow using `django-allauth`.
- **Multi-Vendor Engine**: Dedicated profiles and dashboards for sellers.
- **Carify Command Center**: A premium admin interface built with `django-unfold` for advanced platform management.
- **E-commerce Workflow**:
    - Global Catalogs (Categories)
    - Specimen Management (Products with multi-media support)
    - Regional Order Tracking
    - Preservation Rituals (Service bookings for car care)
- **Stripe Integration**: Secure checkout and payment processing.
- **Responsive UI**: Glassmorphic search, interactive grids, and mobile-optimized layouts.
- **Elite Experience**: High-contrast dark mode with vibrant accents.

## 3. Technology Stack
- **Backend**: Django 6.0.4 (Python)
- **Database**: SQLite (Development) / PostgreSQL or MySQL (Production ready)
- **Styling**: Vanilla CSS with "Industrial Tech" design system.
- **Admin UI**: Django Unfold (Tailwind-based premium admin)
- **Payments**: Stripe API
- **Static Files**: WhiteNoise for efficient static and media serving.
- **Localization**: Support for English, Spanish, French, and Arabic.

## 4. Design Guidelines (Industrial Tech Aesthetic)
- **Background**: #231F20 (Rich Charcoal)
- **Accents**: #F3811F (Electric Orange)
- **Typography**: 
    - Headings: Space Grotesk

## 5. Technical Architecture
- **Root Directory**: `carify/`
- **Project Folder**: `carify_project/` (Settings and URL routing)
- **Main App**: `carify_app/` (Models, Views, Templates)
- **Environment**: Virtual environment managed via `./env/`
- **Dependencies**: Listed in `requirements.txt`

## 6. Setup & Execution
- **Activation**: `env\Scripts\activate` (Windows)
- **Dependencies**: `pip install -r requirements.txt`
- **Migrations**: `python manage.py migrate`
- **Running Server**: `python manage.py runserver`
- **Default Port**: 8000 (or 8001 as configured in recent session)

## 7. Admin & Management
- **Admin URL**: `/admin/`

- **Key Modules**:
